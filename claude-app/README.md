# AI秘書（Claudeアプリ版）手順書

Claudeアプリ（claude.ai・スマホアプリ・デスクトップアプリ）の機能だけで動くAI秘書。**プログラムの起動やAPIキーは不要で、月額プランの範囲内で使える。**

## 構成

| ファイル | 使い道 |
|---|---|
| `investment-secretary/` | スキル本体。レポートの作り方・書式・注意事項を Claude に教える |
| `project-instructions.md` | プロジェクトの「指示」欄に貼る文章 |
| `watchlist.md` | ウォッチリストのひな形。プロジェクトのナレッジに入れる |
| `interview-training/` | 大学推薦入試（学校推薦型・総合型選抜）の面接練習スキル。使い方は下の「面接トレーニング」 |
| `student-profile.md` | 面接練習用の受験生プロフィールのひな形 |

## 必要なもの

- Claude の有料プラン（Pro / Max など）
- 設定 → 機能 で「Web検索」と「スキル（Skills）」がオンになっていること

## セットアップ（初回だけ・10分ほど）

### 手順1: スキルを追加する

1. `investment-secretary.skill`（または `investment-secretary` フォルダを zip にしたもの）を用意する。
2. claude.ai の **設定 → 機能（Capabilities）→ スキル** で「スキルをアップロード」を選び、ファイルを選ぶ。
3. 一覧に `investment-secretary` が出て、オンになっていれば完了。

> チャットにファイルカードで届いた場合は、カードの「スキルを保存」ボタンでも追加できる。

### 手順2: プロジェクトを作る

1. 左メニューの **プロジェクト → 新規プロジェクト**。名前は「AI秘書」など。
2. プロジェクトの **指示（Instructions）** を開き、`project-instructions.md` の内容をそのまま貼り付けて保存。

### 手順3: ウォッチリストを登録する

1. `watchlist.md` を開き、表を自分の銘柄に書き換える（日本株は4桁の証券コード、米国株はティッカー）。
2. プロジェクトの **ナレッジ（Project knowledge）** の「＋」から「テキストコンテンツを追加」を選ぶ。タイトルを「ウォッチリスト」にして、書き換えた表を貼り付ける（ファイルとしてアップロードしてもよい）。

## 毎日の使い方

プロジェクト「AI秘書」の中で新しいチャットを開いて、話しかける。

| やりたいこと | 話しかけ方の例 |
|---|---|
| 毎日のレポート | 「今日のまとめ」 |
| 市場全体 | 「今の相場どう？」 |
| 1銘柄を詳しく | 「トヨタについて調べて」 |
| 比較 | 「トヨタとホンダを比べて」 |
| 決算 | 「ソニーの最新の決算のポイントは？」 |
| 予定 | 「今週ウォッチリストに関係ある決算や指標は？」 |

スマホアプリでも同じプロジェクトを開けば使える。

### ウォッチリストを変えたいとき

1. チャットで「任天堂をウォッチリストに追加して」と頼む。
2. 更新後の一覧が表示されるのでコピーする。
3. プロジェクトのナレッジの「ウォッチリスト」を開いて、中身を置き換える。

（Claude はプロジェクトのファイルを直接書き換えられないため、この手順になる。）

## できること・できないこと

| | |
|---|---|
| できる | Web検索による株価・ニュースの収集、出典付きのレポート、比較表、決算の要約、スマホからの利用、会話履歴の保存 |
| できない | リアルタイムの正確な株価（検索で見つかった時点の値になる）、ウォッチリストの自動更新、決まった時刻の自動レポート作成 |

株価はWeb検索で見つけた値なので、取引時間中は数分〜数十分遅れていることがある。レポートには「〇時点」が書かれるので、それを目安にする。

## 面接トレーニング（大学推薦入試）

`interview-training` スキルを入れると、Claude が面接官役になって模擬面接をし、終わったら観点別の点数・良かった点・直す点・言い直しの例を返す。

### セットアップ
1. `interview-training.skill` を、手順1と同じく **設定 → 機能 → スキル** からアップロードする。
2. 新しいプロジェクト（例:「面接練習」）を作る。投資のプロジェクトとは分けたほうが、話がまざらない。
3. `student-profile.md` を書き換えて、プロジェクトのナレッジに「受験生プロフィール」として入れる。志望理由書・自己推薦書もここに貼る。
4. Web検索をオンにしておくと、志望学部のアドミッションポリシーや最近の時事を確かめてから質問する。

### 使い方
| やりたいこと | 話しかけ方の例 |
|---|---|
| 本番どおりの通し練習 | 「模擬面接して」「面接官3人でやって」 |
| 苦手な質問だけ | 「志望理由だけ3回練習したい」 |
| 準備の全体像 | 「聞かれそうな質問を出して」 |
| 口頭試問 | 「経済学部の口頭試問の練習」 |
| プレゼン＋質疑 | 「このプレゼン原稿を聞いて質問して」 |
| 集団討論 | 「集団討論の練習をしたい」 |
| 伸びの確認 | 「前回と比べてどう？」 |

- 質問は1つずつ出るので、1つ答えてから送る。止めたいときは「中断」と送る。
- スマホアプリの **音声モード** を使うと、声に出して答える練習になる。
- 講評の最後に出る「練習の記録」を、ナレッジの「面接練習の記録」ファイルに足していくと、次回から点数の推移を比べられる。
- 丸暗記用の模範解答は出さない設計になっている（本番の深掘りで崩れるため）。本人の経験をもとに、話の骨組みと言い直しの例を返す。

## 料金

月額プランに含まれる。追加料金はかからない。ただし Web 検索を何度も使う「今日のまとめ」は1回の会話が長くなるので、プランの利用上限に早めに達することがある。上限に達したら、リセットされるまで待つ。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| レポートの形式にならない | 設定でスキルがオンか確認。「investment-secretary スキルを使って今日のまとめ」と頼んでみる |
| ウォッチリストの銘柄が無視される | プロジェクトの中のチャットか確認（プロジェクト外ではナレッジが読めない） |
| 「検索できない」と言われる | 設定で Web 検索をオンにする |
| 数値が古い | 「最新の値を検索し直して」と頼む。休日・取引時間外は前営業日の値になる |
