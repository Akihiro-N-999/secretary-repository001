# 受験生プロフィール（補足用・なくてもよい）

面接練習（interview-training スキル）では、**自己推薦書をそのままプロジェクトのナレッジに入れれば、それが受験生プロフィールになる。** ファイル（PDF・Word・テキスト）をアップロードしても、本文を貼ってもよい。Claude が書類から志望先・活動・将来の夢などを読み取り、最初の練習で「こう読み取りました」と確かめてくれる。

このファイルは、**自己推薦書に書いていないこと** を伝えたいときだけ使う。わかるところだけ書けばよい。氏名・高校名・住所は書かなくてよい。

## 自己推薦書に書いていないこと
| 項目 | 内容 |
|---|---|
| 大学・学部・学科（書類にない場合） | 例: 〇〇大学 経済学部 経済学科 |
| 入試区分 | 例: 学校推薦型選抜（公募制）／総合型選抜／指定校推薦 |
| 面接の形式 | 例: 個人面接 15分・面接官3人／口頭試問あり／プレゼン5分＋質疑 |
| 本番の日付 | 例: 2026-11-20 |
| 併願先 | 例: △△大学 経済学部（一般選抜） |

## 書類に入りきらなかった材料
- 例: 書類には書かなかった部活の経験、最近読んだ本

## 練習で重点を置きたいこと
- 例: 深掘りされると詰まる／志望理由が長くなる／時事が苦手
