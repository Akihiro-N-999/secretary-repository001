# 受験生プロフィール

面接練習（interview-training スキル）で使う。プロジェクトのナレッジに「受験生プロフィール」として入れておくと、毎回説明しなくても本番に近い練習ができる。わかるところだけ書けばよい。氏名・高校名・住所は書かなくてよい。

## 志望先
| 項目 | 内容 |
|---|---|
| 大学・学部・学科 | 例: 〇〇大学 経済学部 経済学科 |
| 入試区分 | 例: 学校推薦型選抜（公募制）／総合型選抜／指定校推薦 |
| 面接の形式 | 例: 個人面接 15分・面接官3人／口頭試問あり／プレゼン5分＋質疑 |
| 本番の日付 | 例: 2026-11-20 |
| 併願先 | 例: △△大学 経済学部（一般選抜） |
