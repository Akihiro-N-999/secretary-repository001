## 1. 概要

ブラウザから話しかけられる「AI秘書」の Web アプリ。最初の機能として **投資情報のとりまとめ** を担当する。

| 項目 | 内容 |
|---|---|
| 利用形態 | Web アプリ (PC・スマホのブラウザ) |
| 言語 | Python 3.10 以上 (動作確認: 3.13) |
| AI | Claude API (`claude-opus-5-5`) / 公式 SDK `anthropic` |
| Web フレームワーク | FastAPI + Uvicorn |
| 市場データ | yfinance (Yahoo Finance、API キー不要) |
| ニュース | Claude の Web 検索ツール (Anthropic のサーバー側で実行) |
| 保存 | ウォッチリストのみ JSON ファイル。会話はメモリ上 (再起動で消える) |

## 2. 実施した作業 (このリポジトリで行ったこと)

1. 要件の確認: 利用形態 = Web アプリ、最初の機能 = 投資情報のとりまとめ、言語 = Python。

4. 自動テスト 22 件を作成し、すべて成功 (Claude と株価取得は偽物に差し替え、API キー・ネットワーク不要)。
5. 実サーバーを起動し、画面表示 (PC・スマホ幅、ライト・ダーク)、ウォッチリストの追加・削除、API キー未設定時のエラー表示を確認。

## 3. 機能仕様

### 3.1 チャット

- 入力欄に質問を書いて送信 (Enter で送信、Shift+Enter で改行。日本語変換中の Enter は送信しない)。
- 回答は **ストリーミング** で少しずつ表示し、Markdown (表・リンクなど) として整形する。
- 処理中は「株価を取得中」「Webでニュースを検索中」など、いま何をしているかを表示する。
- 同じ会話の中では前のやり取りを覚えている。「新しい会話」で履歴を破棄する。
- 送信のたびに現在日時 (JST) をメッセージの先頭に付けて Claude に渡す (「今日」の解釈のため)。

### 3.2 クイック操作ボタン

| ボタン | Claude への依頼内容 |
|---|---|
| 今日のまとめ | 市場の概況 → ウォッチリスト各銘柄の値動き → 関連ニュース → 注目点 のレポート |
| 市場の概況 | 主要株価指数と為替の現状 |
| 銘柄ニュース | ウォッチリスト銘柄の直近1週間の重要ニュース |

### 3.3 ウォッチリスト

- 画面左 (スマホでは上) で銘柄とメモを追加・削除できる。
- 「調べる」で、その銘柄の株価・1か月の値動き・ニュースのまとめを依頼する。
- チャットで「ソニーを追加して」のように頼んでも、Claude がツールで追加・削除する。
- ティッカーは大文字に揃える。同じ銘柄を再追加するとメモだけ更新する。

### 3.4 AI の振る舞い (システムプロンプトの要点)

- 数値は必ずツールで取得し、推測で書かない。取れなかったものは正直に書く。
- ニュースは Web 検索し、出典 (媒体名・URL) を添える。
- 日本語で、結論から簡潔に。比較は表で。
- 投資助言はしない。売買を断定的に勧めず、最終判断はユーザーが行うものと必要に応じて添える。

## 4. 構成

```
ブラウザ (static/index.html, app.js, style.css)
   │  POST /api/chat  ← SSE で途中経過と回答を受信
   ▼
FastAPI (app.py) ── 会話履歴をメモリに保持
   │
   ▼
Secretary (agent.py) ──── Claude API (claude-opus-5-5, ストリーミング)
   │                         └ web_search (Anthropic 側で実行)
   ▼
ツール実行 (tools.py)
   ├ market.py   … yfinance で株価・推移・指数
   └ storage.py  … data/watchlist.json
```

### 4.1 ファイル一覧

| パス | 役割 |
|---|---|
| `secretary/app.py` | Web API・画面配信。会話ごとのロック、エラーを画面向けメッセージに変換 |
| `secretary/agent.py` | Claude との会話ループ。システムプロンプト、モデル設定 |
| `secretary/tools.py` | ツール定義 (JSON Schema)、入力検証、実行 |
| `secretary/market.py` | 株価・価格推移・市場概況の取得 |
| `secretary/storage.py` | ウォッチリストの JSON 保存 |
| `secretary/static/` | 画面 (HTML/CSS/JS) |
| `tests/test_secretary.py` | 自動テスト |

## 5. Claude との連携仕様

### 5.1 リクエスト設定

| 設定 | 値 | 理由 |
|---|---|---|
| model | `claude-opus-5-5` | 現行の標準モデル |
| max_tokens | 64000 | ストリーミングなのでタイムアウトの心配がなく、長いレポートでも途切れにくい |
| effort | `medium` | チャット用途で速度と品質のバランスを取る (`agent.py` で変更可) |
| thinking | 指定なし (このモデルでは常に自動) | |
| cache_control | 自動キャッシュ | システムプロンプト・ツール定義・過去の会話を再利用し、料金と待ち時間を削減 |
| fallbacks | `"default"` (beta `server-side-fallback-2026-07-01`) | 安全分類器が回答を見送った場合、サーバー側で推奨モデルに自動で切り替える |

### 5.2 ツール

| 名前 | 種類 | 内容 |
|---|---|---|
| `get_quotes` | 自前 | 最大10銘柄の現在値・前日比・52週高安・時価総額・PER・配当利回り・セクター |
| `get_price_history` | 自前 | 期間 (5d/1mo/3mo/6mo/1y/5y) の騰落率・高安・年率ボラティリティ・終値 (最大30点に間引き) |
| `get_market_overview` | 自前 | 日経平均・TOPIX・NYダウ・S&P500・NASDAQ・ドル円・VIX |
| `list_watchlist` | 自前 | ウォッチリスト取得 |
| `add_to_watchlist` | 自前 | 追加 (既存ならメモ更新) |
| `remove_from_watchlist` | 自前 | 削除 |
| `web_search` | サーバー側 (`web_search_20260209`) | ニュース検索。1回の依頼で最大8回、地域は日本 |

### 5.3 会話ループ (1回の送信の流れ)

1. 前回ツール実行中に中断されて結果のない呼び出しが残っていれば、「中断されました」という結果を補って履歴を正しい形に戻す。
2. 日時付きのユーザーメッセージを履歴に追加。
3. Claude にストリーミングで送信し、文字と処理状況を画面へ流す。
4. 応答を **そのまま** 履歴に追加する (追記のみで、過去の履歴は書き換えない)。
5. 停止理由ごとの処理:
   - `pause_turn` (Web 検索の途中) → そのまま続きを依頼
   - `refusal` (回答見送り) → エラー表示して終了
   - ツール呼び出しあり → 入力を検証して実行 (複数あれば並列)、結果をまとめて返し 3. へ
   - `max_tokens` → 途中で切れた旨を表示 (切れたツール入力は実行しない)
   - それ以外 → 完了
6. 1回の送信につき最大20往復で打ち切る。

### 5.4 入力検証

ツール入力はストリーミング (`eager_input_streaming`) で受け取るため、API 側の検証がない。実行前に `validate_input` で必須項目・型・件数・期間の値を確認し、不正なら実行せずエラー結果を Claude に返して直させる。JSON として壊れていた場合は同じリクエストを最大2回やり直す。

## 6. Web API

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/` | 画面 |
| POST | `/api/chat` | `{"conversation_id": 省略可, "message": "..."}` → SSE |
| DELETE | `/api/conversations/{id}` | 会話履歴を破棄 |
| GET | `/api/watchlist` | 一覧 |
| POST | `/api/watchlist` | `{"symbol": "7203.T", "note": "任意"}` |
| DELETE | `/api/watchlist/{symbol}` | 削除 (無ければ 404) |

### 6.1 SSE イベント (`data: {JSON}` 形式)

| type | 内容 |
|---|---|
| `conversation` | 会話 ID (最初に1回) |
| `status` | 処理状況 (例: 「株価を取得中」) |
| `text` | 回答の文字の断片 |
| `error` | 画面に出すエラーメッセージ |
| `done` | 完了 |

### 6.2 エラー時の表示

| 状況 | 表示 |
|---|---|
| API キー無効 | 「APIキーが無効です…」 |
| API キー未設定 | 「エラーが発生しました: … ANTHROPIC_API_KEY が設定されているか確認してください」 |
| 利用上限 (429) | 「利用上限に達しました…」 |
| その他の API エラー | ステータスコードとメッセージ |
| 接続失敗 | 「Claude API に接続できませんでした」 |
| 同じ会話への同時送信 | 「前の回答を作成中です…」 |
| 株価が取れない | Claude にエラー結果が渡り、回答の中で「取得できなかった」と説明される |

## 7. データ

- ウォッチリスト: `data/watchlist.json` (環境変数 `SECRETARY_DATA_DIR` で変更可)。一時ファイルに書いてから置き換えるので、書き込み途中で壊れにくい。
  ```json
  [{"symbol": "7203.T", "note": "トヨタ", "added_at": "2026-10-24T13:46:47"}]
  ```
- 会話履歴: サーバーのメモリのみ。再起動で消える。

## 8. 制約・注意点

- **個人利用を想定**: ログイン機能はない。インターネットに公開すると誰でも API キーを使えてしまうため、自分の PC (localhost) で使うこと。
- yfinance は非公式の取得方法のため、Yahoo 側の変更で動かなくなることがある。価格は遅延している場合がある。
- 表示される情報は参考情報であり、投資助言ではない。
- 料金: Claude API は従量課金 (Opus 5.5: 入力 $4 / 出力 $20 per 100万トークン、Web 検索は別途)。「今日のまとめ」は検索とツールを多く使うため、1回あたりの消費が大きめ。
